# MangoCare

MangoCare is an AI-powered mango cultivation management and disease detection system developed for Sri Lanka.

## Main Features

- Mango leaf disease detection
- Mango fruit disease detection
- Smart cultivation advisory
- Historical and current weather integration
- Disease management and prevention guidance
- User authentication and profile management
- Prediction and advisory history

## Technologies

### Frontend
- React
- Vite

### Backend
- FastAPI
- Python
- SQLAlchemy
- MySQL

### Machine Learning
- EfficientNetB2 - Leaf Disease Detection
- EfficientNetB0 - Fruit Disease Detection
- Random Forest - Smart Advisory
